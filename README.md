# Data Professional Survey Analysis (Power BI)

An interactive Power BI dashboard analyzing survey data from 630 data professionals globally to uncover insights into salaries, industry trends, programming languages, and job satisfaction.

## Live Preview & Files
* **Power BI File:** [`dashboard_career_analysis.pbix`](./dashboard_career_analysis.pbix)
* **Preview Image:** [`dashboard_career_analysis.jpg`](./dashboard_career_analysis.jpg)
* **Dataset:** [`dataset_career_analysis.xlsx`](./dataset_career_analysis.xlsx)

## Key Insights & Features
* **Salary Analytics:** Breaks down the average salary by job title (Data Scientists and Data Engineers leading at $94k+ and $65k+ average).
* **Demographics & Geography:** Visualizes survey count by country (US, India, UK, Canada) and gender distribution (74% Male, 25% Female).
* **Tech Stack Preferences:** Highlights Python as the dominant programming language (420 users) over R and JavaScript.
* **Education Breakdown:** Tracks highest qualifications, showing Bachelors (329) and Masters (192) as the most common degrees.
* **Workplace Sentiment:** Tracks age distributions (average 29.8) and workplace happiness metrics regarding salary and work-life balance.

## Technology Used
* **Data Source:** Excel Survey Data
* **BI Tool:** Microsoft Power BI
* **DAX & Data Modeling:** Used for custom aggregations, salary filtering, and metric tracking.
